GrowBiz API shartnomasi (MVP)

Base URL: http://localhost:8001

Auth: Authorization: Bearer <token> (auth/health dan tashqari hammasi)

Health / Auth

  • GET /health
  • POST /api/v1/auth/register {name, phone, password}
  • POST /api/v1/auth/login {phone, password}
  • GET /api/v1/auth/me

Org

  • GET/POST /api/v1/org/organizations
  • GET/PATCH/DELETE /api/v1/org/organizations/{id}
  • GET/POST /api/v1/org/organizations/{id}/departments
  • PATCH/DELETE /api/v1/org/departments/{id}
  • GET/POST /api/v1/org/organizations/{id}/employees
  • PATCH/DELETE /api/v1/org/employees/{id}

Task Board

  • GET /api/v1/boards?organization_id=
  • POST /api/v1/boards {organization_id, name} → default lists: To Do / In Progress / Done
  • GET /api/v1/boards/{id}
  • DELETE /api/v1/boards/{id}
  • POST /api/v1/boards/{id}/lists
  • PATCH/DELETE /api/v1/boards/lists/{id}
  • GET/POST /api/v1/boards/lists/{id}/cards
  • PATCH/DELETE /api/v1/boards/cards/{id} (move: list_id)

CRM

  • GET/POST /api/v1/crm/pipelines (POST stages default: New→Lost)
  • GET /api/v1/crm/pipelines/{id}
  • GET/POST /api/v1/crm/leads
  • PATCH/DELETE /api/v1/crm/leads/{id}
  • GET/POST /api/v1/crm/deals
  • PATCH/DELETE /api/v1/crm/deals/{id} (move stage: stage_id)

LMS

  • GET/POST /api/v1/lms/courses
  • GET/PATCH/DELETE /api/v1/lms/courses/{id}
  • POST /api/v1/lms/courses/{id}/lessons
  • PATCH/DELETE /api/v1/lms/lessons/{id}
  • GET /api/v1/lms/progress/me?course_id=
  • PUT /api/v1/lms/progress {lesson_id, completed, progress_percent}

OpenAPI: http://localhost:8001/docs
